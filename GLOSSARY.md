# Junior Assistant

A personal assistant for finding local files and organizing work across registered projects and personal life.

## Language

**Project**:
A named working folder to which records can belong. An archived project preserves its identity and records but is no longer selected automatically or searched through its project registration.

**Search root**:
An explicitly registered folder within which files and folders may be found. A search root may exist independently of a project.

**Record**:
A tracked piece of work, classified as a task or bug, belonging to a project or to personal work.
_Avoid_: GitHub issue, ticket

**Task**:
A record describing work to do.

**Bug**:
A record describing a defect to address, using the same lifecycle as a task.

**Personal record**:
A record with no project owner.

**Planned date**:
The calendar day on which the user intends to work on a record.

**Due date**:
The calendar day by which a record should be finished.

**Missed plan**:
An unfinished record whose planned date is before today.

**Active record**:
A record with status open or in-progress.
